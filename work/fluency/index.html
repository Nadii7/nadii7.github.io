Fluency live

Language learning · Mobile app built from scratch

Check how many lessons are left on a plan, watch a teacher’s introduction and book a session. Before joining, learners can test their connection, microphone and camera.

  • Flutter
  • Riverpod
  • RealtimeKit UI & Core
  • iOS session lifecycle

My contribution

I built the booking and live lesson flows in Flutter. I also forked RealtimeKit UI and Core to coordinate meeting exit with native listener cleanup. On iOS, a new meeting client waits for the previous session’s cleanup to finish before it starts.

The challenge

A live session has to end cleanly before the next one begins.

Make meeting cleanup awaitable.

Awaiting cleanup in the UI only works when the core and native layers also return a completion signal. My changes connect those layers and serialize pending iOS cleanup before preparing a fresh client for the next session.

The trade-off

The integration gains an explicit lifecycle boundary. Maintaining a fork also means tracking upstream SDK changes and keeping the app and platform packages compatible.

Evidence in the implementation

The Core package exposes completion signals for removing meeting and participant listeners. The Flutter UI can await those signals when a learner leaves a call.
