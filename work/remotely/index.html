The challenge

Different tasks need different inputs and conditional next steps.

Separate workflow evaluation from the action’s visual presentation.

Submission controllers delegate through use cases and repositories. A separate condition controller evaluates criteria and updates target actions; the screen observes the resulting schedule state.

The trade-off

Separating rules from the view makes the flow easier to follow, while conditional actions still need careful scenario testing. Media capture adds permission, device-lifecycle and attachment-handling responsibilities.

Evidence in the implementation

I put camera ownership in a Riverpod controller. It releases the camera when the app goes into the background and reopens the preview on return if there’s no photo under review. Retaking a shot deletes the discarded temporary file.
